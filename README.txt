Важное:
- Используйте отдельный тестовый TRON-кошелёк.

- Деривация: m/44'/195'/0'/0/{index}; по умолчанию index=0.
- Перед использованием проверьте показанный программой адрес.
- TRON Grid API key используется для запросов к API и не является private key.
- Проект не является аудированным финансовым ПО. Сначала тестируйте на небольшой сумме.
